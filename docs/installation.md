# Instalação — moodle-editor_tiptap

## Requisitos de Sistema

- **Moodle**: 4.0 ou superior
- **PHP**: 7.4 ou superior
- Navegadores modernos com suporte a JavaScript habilitado.

---

## Passo a Passo de Instalação

1. Acesse a pasta de editores da sua instalação do Moodle:
   ```bash
   cd /caminho/do/moodle/lib/editor
   ```
2. Clone o repositório nomeando a pasta como `editor_tiptap`:
   ```bash
   git clone https://github.com/moodle-by-kelsoncm/moodle-editor_tiptap.git editor_tiptap
   ```
3. Acesse a página de administração do Moodle em **Administração do site → Notificações**.
4. Siga as instruções na tela para concluir a criação de tabelas e atualização no banco de dados.
