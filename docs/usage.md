# Guia de Uso — moodle-editor_tiptap

## Seleção do Editor pelo Usuário

1. O usuário pode acessar **Preferências de perfil → Preferências de editor**.
2. Selecionar **Editor TipTap** na lista de opções.
3. Ao abrir qualquer formulário do Moodle com campo de texto formatado, a barra de ferramentas do TipTap será carregada.
