Configuração
============

Configurações do Plugin
-----------------------

1. Acesse: **Administração do site > Plug-ins > Editores de texto > Editor TipTap**.
2. Marque/desmarque os botões da barra de ferramentas que deseja disponibilizar para os usuários.
3. Salve as alterações.

Ativação do Editor no Moodle
----------------------------

1. Acesse: **Administração do site > Plug-ins > Editores de texto > Gerenciar editores**.
2. Clique no ícone de olho para **Habilitar** o "Editor TipTap".
3. Altere a ordem de prioridade dos editores usando as setas para cima/baixo se desejar torná-lo o editor padrão.
