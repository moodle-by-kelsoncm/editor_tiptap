Usage
=====

Choosing the editor
-------------------

When the TipTap editor is not the default editor of the site, each user can choose it:

1. Open **Preferences > Editor preferences**.
2. Select **TipTap editor** and save.

Editing text
------------

Every HTML text field of Moodle forms (forum posts, descriptions, pages...) opens with the toolbar above the text.

- Choose **Paragraph** or **Heading 1** to **Heading 3** in the selector to change the current block.
- Select text and click **B**, **I** or **U** to format it, or a list button to turn the lines into a list.
- To add a link, select the text, click the link button, type the URL and click **Save**.
- **Undo** and **Redo** revert or repeat the last changes.

The text is saved when the form is submitted.
