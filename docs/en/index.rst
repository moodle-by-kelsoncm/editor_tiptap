Overview - moodle-editor_tiptap
==================================

**moodle-editor_tiptap** is a modern WYSIWYG editor plugin for Moodle based on the TipTap library, offering a rich, minimalist, and high-performance text editing experience.

Key Features
------------

- **Modern & Responsive Interface**: Clean design adaptable to mobile devices and desktops.
- **Full Text Formatting**: Bold, italic, underline, ordered and unordered lists, headings (H1, H2, H3), links, and undo/redo buttons.
- **Dark Mode**: Visual support for dark themes.
- **Administrative Settings**: Granular enabling and disabling of toolbar action buttons.
