Uso
===

Escolhendo o editor
-------------------

Quando o TipTap não é o editor padrão do site, cada usuário pode escolhê-lo:

1. Abra **Preferências > Preferências do editor**.
2. Selecione **TipTap editor** e salve.

Editando o texto
----------------

Todo campo de texto HTML dos formulários do Moodle (mensagens de fórum, descrições, páginas...) abre com a barra acima do texto.

- Escolha **Paragraph** ou **Heading 1** a **Heading 3** no seletor para mudar o bloco atual.
- Selecione o texto e clique em **B**, **I** ou **U** para formatá-lo, ou num botão de lista para transformar as linhas em lista.
- Para inserir um link, selecione o texto, clique no botão de link, digite a URL e clique em **Salvar**.
- **Desfazer** e **Refazer** revertem ou repetem as últimas alterações.

O texto é salvo quando o formulário é enviado.
