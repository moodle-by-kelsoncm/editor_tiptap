Configuração
============

Configurações do plugin
-----------------------

1. Acesse **Administração do site > Plugins > Editores de texto > TipTap editor**.
2. Ligue ou desligue os botões da barra: negrito, itálico, sublinhado, lista com marcadores, lista numerada e link.
   O seletor de bloco (parágrafo e títulos) e os botões desfazer e refazer aparecem sempre.
3. Salve as alterações.

Habilitando o editor
--------------------

1. Acesse **Administração do site > Plugins > Editores de texto > Gerenciar editores**.
2. Habilite o **TipTap editor** (ícone de olho).
3. Mova-o para o topo da lista com as setas para torná-lo o editor padrão do site.
