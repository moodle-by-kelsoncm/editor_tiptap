# Visão Geral — moodle-editor_tiptap

O **`moodle-editor_tiptap`** é um plugin de editor WYSIWYG moderno para o Moodle baseado na biblioteca TipTap, oferecendo uma experiência de edição de texto rica, minimalista e de alta performance.

---

## 🚀 Principais Recursos

- **Interface Moderna & Responsiva**: Design limpo adaptável a dispositivos móveis e desktops.
- **Formatação de Texto Completa**: Negrito, itálico, sublinhado, listas ordenadas e não ordenadas, cabeçalhos (H1, H2, H3), links e botões de desfazer/refazer.
- **Modo Escuro (Dark Mode)**: Suporte visual para temas escuros.
- **Configurações Administrativas**: Habilitação e desabilitação granular dos botões de ação na barra de ferramentas.
